# 10 - 核心数据流

## 概述

本文档描述后端核心业务流程的数据流。

---

## 1. 用户注册/登录流程

```
┌──────────────────────────────────────────────────────────────────┐
│                         前端                                      │
│  POST /api/auth/register { username, email, password }          │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│                    auth_router.py                                  │
│  POST /api/auth/register                                          │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│                    auth_service.register()                         │
│  1. bcrypt.hashpw(password)                                     │
│  2. 生成 token = f"local_{uuid}"                                │
│  3. 写入 auth_users + auth_tokens                               │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│                    响应 { token, user_info }                       │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│                    前端存储 Token                                  │
│  localStorage.setItem('James_access_token', token)               │
└──────────────────────────────────────────────────────────────────┘
```

## 2. 聊天消息流程

```
┌──────────────────────────────────────────────────────────────────┐
│                         前端                                      │
│  POST /api/chat { messages, session_id, canvas_id, tool_list }   │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│                    chat_router.py                                 │
│  POST /api/chat → chat_service.handle_chat()                    │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│                    chat_service.handle_chat()                     │
│  1. 保存用户消息 → db_service.create_message()                   │
│  2. 创建/获取 AgentManager                                       │
│  3. 启动 Agent.stream()                                         │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│                    LangGraph Agent                                │
│  Agent 处理 messages，调用工具                                    │
└──────────────────────────────────────────────────────────────────┘
                              │
              ┌───────────────┴───────────────┐
              ▼                               ▼
┌──────────────────────────┐    ┌──────────────────────────────┐
│     文本输出 (Delta)      │    │      工具调用 (ToolCall)       │
│  broadcast_session_update │    │   broadcast_session_update   │
│  (type='Delta', text)    │    │   (type='ToolCall', id, name) │
└──────────────────────────┘    └──────────────────────────────┘
              │                               │
              │       ┌───────────────────────┘
              │       ▼
              │  ┌──────────────────────────────────┐
              │  │       工具执行结果                 │
              │  │   broadcast_session_update         │
              │  │   (type='ToolCallResult', ...)    │
              │  └──────────────────────────────────┘
              │                               │
              └───────────────┬───────────────┘
                              ▼
                    ┌──────────────────────────┐
                    │    会话完成 (Done)         │
                    │ broadcast_session_update   │
                    │ (type='Done')             │
                    └──────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│                    WebSocket 广播到前端                            │
└──────────────────────────────────────────────────────────────────┘
```

## 3. Socket.IO 连接流程

```
┌──────────────────────────────────────────────────────────────────┐
│                    前端连接 Socket.IO                              │
│  io('http://localhost:57988', { auth: { token } })                │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│                    handlers.connect(sid, environ, auth)           │
│  token = auth.get('token')                                       │
│  if token.startswith('local_'):                                │
│      valid, user_info = validate_local_token(token)              │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│                    emit('connected', { authenticated })           │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│                    前端监听 session_update                        │
│  socket.on('session_update', handler)                            │
└──────────────────────────────────────────────────────────────────┘
```

## 5. 图片生成流程

                              ▼
┌──────────────────────────────────────────────────────────────────┐
│                    tool_service.get_tool('generate_image')        │

└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐

                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│                    Provider 生成图片                              │

                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│                    broadcast_session_update(                      │
│                      type='ImageGenerated',                      │
│                      image_url=...)                               │

```

## 6. 工具确认流程

```
┌──────────────────────────────────────────────────────────────────┐
│                    Agent 调用工具 (需要确认)                       │
│  broadcast_session_update(                                       │
│    type='ToolCallPendingConfirmation',                           │
│    id, name, arguments                                           │
│  )                                                               │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│                    前端显示确认弹窗                                 │

└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│                    POST /api/tool_confirmation                    │
│  { session_id, tool_call_id, confirmed: true/false }            │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│              tool_confirmation_manager.confirm()                   │
│  → WebSocket 推送 ToolCallConfirmed / ToolCallCancelled         │
└──────────────────────────────────────────────────────────────────┘
```

## 7. 配置更新流程

```
┌──────────────────────────────────────────────────────────────────┐
│                    POST /api/config { provider: { api_key } }    │
└──────────────────────────────────────────────────────────────────┘
                               │
                               ▼
┌──────────────────────────────────────────────────────────────────┐
│                    config_service.update_config()                  │
│  1. 深合并到 app_config                                          │
│  2. 写入 config.toml                                             │
└──────────────────────────────────────────────────────────────────┘
                               │
                               ▼
┌──────────────────────────────────────────────────────────────────┐
│                    tool_service.initialize()                        │
│  ToolLoader.initialize() → 加载 Provider 工具                    │
│  └── tool_registry.py (存储)                                     │
└──────────────────────────────────────────────────────────────────┘

                              ▼
